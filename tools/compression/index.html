Compression Tool

Originally, this tool was used to compare CBOR and DEFLATE. This was to assess their use for encoding gamestates in a url with base64 encoding. Of course, CBOR is not a compression algorithm, but it may have been useful for this case. CBOR was removed from this page since it's output was larger than DEFLATE, required a third-party library, and requres JSON-able input.
